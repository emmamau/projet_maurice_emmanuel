Consommation d'une API REST avec Angular (Observable → Signal)

Concept Pédagogique De l'Observable au Signal Angular

Le PollutionService effectue un appel HttpClient.get() qui produit un Observable<Pollution[]>. Dans le composant, la fonction toSignal() (de @angular/core/rxjs-interop) transforme ce flux en un Signal réactif accessible directement dans le template via pollutions().
